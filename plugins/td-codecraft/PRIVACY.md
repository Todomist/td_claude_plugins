# Privacy

td-codecraft is a set of instructions (skills) for Claude Code. It collects no data, stores no
data and sends nothing anywhere: it has no MCP servers, no scripts and no network access. Its one
hook prints one local file at the start of every chat (when to suggest the skills).

The skills work on the user's own project through Claude Code's normal tools (reading files,
writing `.claude/td-codecraft/`), with the user's permission. What Claude Code itself does with
that work is covered by Anthropic's terms and privacy policy, not by this plugin.

Questions: https://github.com/Todomist/td_claude_plugins/issues
